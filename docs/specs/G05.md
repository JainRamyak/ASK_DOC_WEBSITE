- FACT (`backend/src/pipeline.py:179-227`): `ask()` calls no LLM when the gate rejects or the session is missing/empty question; otherwise 1 answer call (+1 rewrite call if `ENABLE_QUERY_REWRITING=true` and `history` given). ## Edge Cases
- Provider default model ID is invalid/deprecated: O7 is recorded as a failure; the run may retry once with an owner-supplied `*_MODEL` env override (counts toward the cap). The default itself is not changed here.
- The gate rejects a question intended as O1/O3 (the documented G22 risk): record as observed gate behavior with the top score, choose a more specific question (counts against no provider cap since no call is made).
- Rate limit / quota (429) mid-run: stop, record, do not loop.
- LLM output varies between runs: O4 uses up to 3 attempts precisely because a single sample proves little; conclusions are worded as "observed in N samples".
- Provider returns empty content: code returns `NOT_FOUND_MESSAGE` silently (`or NOT_FOUND_MESSAGE`); note whether this was indistinguishable from a real refusal.
- Rewrite failure is swallowed by design; O6 must confirm from the log that a rewrite actually occurred rather than inferring it from the answer.
